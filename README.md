# Sitio personal

Página personal de Luciano Silva-Aguayo, publicada en https://lsilva-a.github.io

Sitio estático, sin dependencias externas: un solo archivo HTML con estilos y comportamiento
incorporados. Bilingüe español e inglés, con selector en la barra superior que recuerda la
elección del visitante.

- `index.html`: sitio publicado.
- `alternativa-serif.html`: versión alternativa con tipografía serif, no publicada.
